# Computação Visual: Jogos pixel art

## Uma curiosidade sobre os jogos

Uma coisa que acho interessante é que, mesmo com os gráficos dos jogos atuais sendo cada vez mais realistas, alguns jogos continuam utilizando **pixel art** como estilo visual.

Pixel art é uma forma de criar imagens utilizando pequenos pixels de maneira intencional. Esse estilo ficou muito conhecido nos primeiros videogames, quando os computadores e consoles tinham limitações de processamento e resolução.

## Por que a pixel art continua sendo usada?

Antigamente, os desenvolvedores precisavam trabalhar com poucas cores e resoluções muito baixas. Por isso, os personagens e cenários precisavam ser representados utilizando uma quantidade pequena de pixels.

Atualmente, os computadores conseguem produzir gráficos muito mais detalhados, mas a pixel art continuou sendo utilizada por escolha artística. Jogos como *Minecraft*, *Stardew Valley* e *Terraria* utilizam estilos visuais baseados em pixels, mesmo podendo utilizar gráficos mais detalhados.

## Conclusão

O que mais achei interessante é que algo que começou principalmente como uma limitação tecnológica acabou se tornando um estilo artístico.

Isso mostra que a Computação Visual não precisa necessariamente buscar imagens cada vez mais realistas. Em alguns casos, limitações visuais podem ser utilizadas de forma criativa para criar uma identidade própria para um jogo.

Além disso, eu gosto bastante de jogos com pixel art e tenho uma certa preferência por esse estilo. Acho interessante como, mesmo utilizando gráficos mais simples, esses jogos conseguem criar personagens, cenários e mundos visualmente marcantes.
